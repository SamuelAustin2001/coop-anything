## How the game works (for co-op)

The tested Steam build is a Windows x64 Unity 5.6.2p4 game using Mono. `Player` samples Rewired actions, Yarn's `DialogueRunner` handles dialogue, and `Continuity` stores numeric story variables and persistent/save data. The assembly has no reference to Unity networking. Save files are serialized as `.dat` files under Unity's persistent-data directory.

Each game instance controls its own Mae movement. The host sends scene and position snapshots, while each screen renders the peer as a sprite-only puppet copied from its local Mae; the puppet has no player controller, camera, collider or physics. Dialogue/interaction input and the numeric `Continuity.vars` dictionary remain host-authoritative. Guest saves are suppressed. Numeric variables are sent in bounded UDP fragments and applied only after a complete snapshot arrives.
